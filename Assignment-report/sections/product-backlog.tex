\subsection{Chi tiết Task 10 và Definition of Done}
Task 10 gồm bốn nội dung: kiểm soát chuyển trạng thái, thanh toán idempotent, kho đồng thời và khuyến mãi/điểm. Đề yêu cầu test chứng minh chặn chuyển sai, gửi hai lần cùng key không tạo trùng và đặt đồng thời không vượt kho.

Lịch sử nhánh an có commit triển khai khóa lạc quan, nhưng bản tích hợp đang dùng khóa dòng cho nguyên liệu. Hai kỹ thuật khác nhau; version trên hồ sơ đổi/hoàn không tự đáp ứng yêu cầu optimistic locking cho tồn kho. Phần này phải được giải quyết hoặc xác nhận chấp nhận phương án thay thế, chưa tự đánh dấu Task 10 đạt hoàn toàn.

Definition of Done: code chạy/build được, đúng tiêu chí; có commit và review; API validate; UI có loading/lỗi; README đủ hướng dẫn. Số lượng commit hoặc tính năng mở rộng không thay thế những điều kiện này.
